# Sistema de Chat com JMS

Aplicação de chat em tempo real desenvolvida com Java utilizando Java Message Service (JMS) e Apache ActiveMQ, com interface gráfica em JavaFX.

## Destaque

O foco do projeto é a comunicação assíncrona entre clientes utilizando mensageria, permitindo desacoplamento e troca de mensagens em tempo real.

A aplicação utiliza:
- Filas e/ou tópicos para envio e recebimento de mensagens
- Produtores e consumidores JMS
- ActiveMQ como broker de mensagens

A JMS é uma API que permite comunicação assíncrona entre aplicações, utilizando modelos como point-to-point e publish/subscribe :contentReference[oaicite:0]{index=0}.

## Tecnologias

- Java
- JavaFX
- JMS (Java Message Service)
- Apache ActiveMQ

## Funcionalidades

- Envio e recebimento de mensagens em tempo real
- Comunicação entre múltiplos clientes
- Interface gráfica simples
- Arquitetura baseada em mensageria

## Observação

Projeto com foco educacional, explorando conceitos de sistemas distribuídos e comunicação assíncrona.
